# LLM-Based Process Discovery and BPMN Generation Artifacts

This repository contains supplementary artifacts associated with a scientific publication presenting an LLM-supported pipeline for process discovery and BPMN model generation from military-health doctrinal documents in the context of the PRIME Alert project.

The repository supports the transparency, traceability, and reproducibility of the presented case study by providing the prompts used throughout the pipeline, intermediate LLM-generated artifacts, and the resulting BPMN process models.

## Repository Structure

### 📁 `generated_process_models/`

This directory contains the final BPMN process models generated for the process candidates selected during the process discovery and assesments stages.

For each generated process model, the directory provides:

- a **BPMN file** containing the editable BPMN 2.0 XML representation;
- a **JPG image** providing a visual representation of the generated process model.

The files cover all process candidates selected for detailed BPMN modeling in the case study.

---

### 📁 `generated_artefacts/`

This directory contains the intermediate structured artifacts generated by the LLM during the individual stages of the proposed pipeline.

The provided artifacts include:

- the generated process landscape;
- identified process candidates;
- candidate assessment records;
- process selection and scoping outputs;
- YAML-based process modeling packages;
- supporting intermediate YAML outputs produced throughout the pipeline.

These artifacts document how the source material was progressively transformed from a doctrinal document into bounded and structured inputs for BPMN generation.

---

### 📁 `prompts/`

This directory contains the prompt formulations used in the individual stages of the proposed pipeline.

The prompts located directly in this directory support the main process discovery and preparation stages, including:

- document analysis and process landscape generation;
- process candidate identification;
- candidate assessment;
- process selection and scoping;
- generation of structured YAML-based modeling packages;
- assessment of the generated process models.

All prompts are provided in the form used to generate the accompanying artifacts.

#### 📁 `prompts/final_bpmn_generation/`

This subdirectory contains the prompts used during the final BPMN model generation stage.

The final generation stage applies the previously proposed multi-step LLM-based BPMN generation workflow. Consequently, these prompts were adopted from the authors' earlier work and are identical to the prompts available in the corresponding repository:

[Generating BPMN Healthcare Process Models Using LLMs – Supplementary Artifacts](https://github.com/xgrik/llm-bpmn-generation-artifacts)

They are included in this repository to provide a complete record of the prompts used across the entire pipeline and to make the case study artifacts self-contained.

---

## Artifact Flow

The repository artifacts correspond to the main stages of the applied pipeline:

1. analysis of the source doctrinal document;
2. generation of a process landscape;
3. identification of process candidates;
4. assessment of the candidates;
5. selection and scoping of processes for detailed modeling;
6. generation of YAML-based modeling packages;
7. generation of BPMN process models;
8. structured assessment of the generated models.

The contents of `generated_artefacts/` represent the intermediate outputs of these stages, while `generated_process_models/` contains the resulting BPMN models.
